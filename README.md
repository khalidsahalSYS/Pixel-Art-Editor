# Pixel Art Editor

A simple workspace for creating and editing pixel art.

## Project notes

This file is a place to collect ideas and useful notes as the editor takes shape.

- Keep the drawing experience focused and easy to use.
- Support pixel-level editing on a clear canvas.
- Consider helpful tools such as a pencil, eraser, fill, color picker, and grid.
- Make it easy to save and export artwork.

## Ideas to explore

- Adjustable canvas size and zoom
- Palette management
- Undo and redo
- PNG export

_Add or update these notes as the project develops._
