# Pixel Art Editor

A simple, responsive web app for creating and editing pixel art on desktop and mobile.

## Run it

Open `index.html` in a browser to use the editor. For installable-app features and offline support, serve the repository over HTTPS (or localhost), since browsers require a secure context for service workers and web-app installation.

## Features

- Pixel canvas with pencil, eraser, fill, and color picker tools
- Built-in color palette and custom color selection
- Adjustable canvas size (8–128 pixels in each dimension) and zoom
- Optional pixel grid
- Undo and redo (also available with Ctrl/Cmd+Z and Ctrl/Cmd+Y)
- Save artwork in the browser and export it as a PNG
- Responsive layout, app icon, web-app manifest, and offline caching for desktop and mobile

To install, open the hosted app in your browser and choose **Install app** or **Add to Home Screen** from the browser menu. Browser support and menu wording may vary.
